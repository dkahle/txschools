2010-11 Academic Excellence Indicator System
Download of All Data

This download is for accessing data for the entire state. These files are large! The data files contain a maximum of 256 fields, in order to be easily imported into any data processing program, or a spreadsheet program such as Microsoft Excel. The corresponding layout files describe the fields in the data files.

For information on the data elements, see the Master Reference for Data Elements used in the AEIS as well as the AEIS Data Dictionary (PDF download).

Notes:

  • The name for each variable is provided as the column head. These names are abbreviated for purposes of programming. To decipher the name, please refer to the Master Reference for Data Elements used in the AEIS.
  • All reports, including these downloads, employ significant masking of performance data in order to comply with the Family Educational Rights and Privacy Act (FERPA). In the download files, masked values are represented with various negative values (-1, -3, -4, -99) indicating the source data are unavailable. For detailed information, please see the Explanation of Masking.
  • These data allow the user to create customized reports. To do so, you will need to write your own data extraction programs to examine these data.
