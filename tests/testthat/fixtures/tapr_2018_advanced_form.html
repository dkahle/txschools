2017-18 TAPR Advanced Data Download

This advanced download includes Numerators, Denominators & Rates used in the 2017-18 Texas Academic Performance Report. The only download format available is comma delimited (*.dat) due to the large size of the files. The data download can exceed 2000 columns. For information on the data elements, see the Master Reference of TAPR Data Elements as well as the TAPR Data Dictionary (statutorily-required data) and Additional TAPR Data found on the comprehensive TAPR HTML system.
